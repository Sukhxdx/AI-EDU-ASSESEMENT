# AI-Powered Educational Assessment and Content Analysis Platform

This project supports **SDG 4 (Quality Education)**, **SDG 9 (Innovation & Infrastructure)**, and **SDG 10 (Reduced Inequalities)** through AI-powered quiz generation, readability analysis, and multilingual glossary creation.

## Run Instructions
1. Install dependencies: `pip install -r requirements.txt`
2. Run app: `streamlit run app.py`
3. Paste or upload text → Click "Analyze" → See quiz, readability, glossary.
