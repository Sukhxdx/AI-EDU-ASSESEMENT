# Synthetic datasets

All CSVs in this folder are generated by `python dataset/generate_data.py`.

They mimic Indian retail-banking activity (INR amounts, UPI/card merchants, PAN/Aadhaar
text, RBI/Nifty headlines) so the models can be trained without confidential bank
extracts. Labels are planted from observable features. Do not treat accuracy numbers
as a claim about live portfolios.

| File | Rows (approx.) | Used by |
| --- | --- | --- |
| `transactions.csv` | 4,000 | Fraud Sentinel |
| `loan_applications.csv` | 2,500 | Credit underwriting |
| `aml_ledger.csv` | 1,800 | AML Watch |
| `customer_queries.csv` | chat utterances | Customer Copilot |
| `kyc_documents.csv` | ID snippets | KYC Intake |
| `spend_merchants.csv` | 1,600 | Spend Insights |
| `news_headlines.csv` | labelled headlines | Market Pulse |
| `investor_profiles.csv` | 800 | Robo-Advisor clustering |
